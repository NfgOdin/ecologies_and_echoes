# Ecologies & Echoes

A Minecraft mod built for **NeoForge 1.21.1**.

## Development Setup

### Requirements
- **Java 21** JDK (or let the Gradle Foojay toolchain resolver fetch it automatically)
- Recommended IDE: IntelliJ IDEA, VS Code, or Eclipse

### Common Commands
- **Build mod JAR**:
  ```bash
  ./gradlew build
  ```
- **Run Client**:
  ```bash
  ./gradlew runClient
  ```
- **Run Server**:
  ```bash
  ./gradlew runServer
  ```
- **Run Data Generation**:
  ```bash
  ./gradlew runData
  ```

## Project Details
- **Minecraft Version**: `1.21.1`
- **NeoForge Version**: `21.1.252`
- **Gradle Plugin**: ModDevGradle (`net.neoforged.moddev`)
- **Mappings**: Parchment + Mojang official
